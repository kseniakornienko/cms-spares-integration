# Синхронизация данных CMS

Интеграционное приложение реализовано в n8n с использованием SQLite. Сценарий получает данные о деталях из CMS, сохраняет и обновляет их в исторической базе, формирует CSV и отправляет его в Report API. 

База данных находится в файле spares_history.sqlite, экспортированный сценарий n8n в "Синхронизация CMS (Корниенко).json".
